ABOUT THE PLATFORM

A modular control plane for MCP services

MCP Uni Hubs is a control plane for organizing users, hubs, and service integrations. It loads application configuration and plugins into a shared runtime, routing each data area to local JSON files or configured PostgreSQL tables. Google sign-in verifies a user's email against a local user record before issuing a signed session. Authenticated users can review application, plugin, secret-store, and hub information in the dashboard. The platform also provides secret resolution and VM orchestration, with provider capabilities determined by the configured integrations.

EXTENSION MODEL

Plugin architecture

Core modules include VM orchestration, access-control decisions, and secret resolution; loading a plugin does not automatically secure its operations.

REQUEST LIFECYCLE

Application flows

Only verified Google emails matching a local user receive a signed session.

SYSTEM OVERVIEW

Solution architecture

Each record area can independently use local JSON or a PostgreSQL table; PostgreSQL connection strings are provided through runtime configuration.

POLICY DECISION MODEL

ACL security architecture

The dashboard’s signed Google session is authentication; it does not mean plugin or data actions have passed an ACL check.

NETWORK BOUNDARIES

Network and connectivity

The internal Secretario URL is configured, not a reachability guarantee. PostgreSQL connectivity is enabled only for areas configured with a runtime connection string. The repository does not define separate subnet or firewall rules.
